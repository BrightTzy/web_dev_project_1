# Kanbae Project 🚀

A modern, beautiful Kanban Board and Dashboard application built with React, Vite, and Tailwind CSS. 
Data is persisted locally in the browser using `localStorage`. No backend required!

## Project Description
Kanbae allows teams to efficiently manage their workflow across three columns: TO DO, DOING, and DONE. It supports rich task management, including custom categories, responsible persons, start/due dates, and smooth drag-and-drop interactions. The built-in Dashboard provides real-time insights with summary statistics and interactive charts powered by Recharts.

## Features
- **Kanban Board**: Drag and drop tasks between columns.
- **Task Management**: Create, edit, and delete tasks.
- **Categories**: Assign existing categories or dynamically add custom ones with color codes.
- **Data Persistence**: All tasks and categories are saved locally (Local Storage) so your work is never lost.
- **Dashboard**: Get insights on task distribution, category breakdown, and completion performance.

## Basic Usage Instructions

### Development Setup
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.
4. Open the provided localhost link in your browser.

### How to use
- **Creating a Task**: Go to the Kanban Board and click the "+ New Task" button.
- **Adding a Category**: Inside the task creation/edit modal, click the "+" button next to the category dropdown to create a custom category with a color.
- **Moving Tasks**: Click and drag a task card between columns, or click the card to edit its status manually.
- **Dashboard**: Navigate to the Dashboard using the sidebar to view your project's metrics. Note that the Completion Performance chart requires tasks to have a Due Date and be marked as DONE.
